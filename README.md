# FlexScreener-Tertiaire
FlexScreener Tertiaire est un outil web de prospection B2B développé pour Tilt Energy qui permet d'identifier les bâtiments tertiaires éligibles à l'effacement électrique. Il croise les données publiques de l'ADEME et de l'API Sirene pour estimer instantanément leur puissance flexible et leurs gains financiers potentiels.
